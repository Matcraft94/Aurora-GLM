.. _guide:

User Guide
##########

Welcome to the Aurora-GLM user guide. This section provides step-by-step
tutorials covering every major feature of the framework, from initial
installation through advanced GAMM modeling.

Aurora-GLM is a Python framework for Generalized Linear Models (GLM),
Generalized Additive Models (GAM), and Generalized Additive Mixed Models
(GAMM). Import the package as ``import aurora``.
